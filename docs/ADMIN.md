# 網頁後台與服務器設定

`cmd/admin` 是網頁後台，`start-local.cmd` 會連同其他服務一起啟動。預設網址是 `http://<這台電腦的 IP>:19090`。

## 登入

後台用 email 認證碼登入，沒有密碼。只有管理員的 email 收得到認證碼。

`.local/environment.json` 裡有四個值：

| 名稱 | 用途 |
|---|---|
| `MAPLEGO_ADMIN_EMAILS` | 內建管理員，以逗號分隔。這裡的人不能從後台移除。 |
| `MAPLEGO_POSTMARK_TOKEN` | Postmark 的 Server API Token。 |
| `MAPLEGO_ADMIN_MAIL_FROM` | 寄件地址，必須是 Postmark 已驗證的 Sender Signature 或網域。 |
| `MAPLEGO_ADMIN_ADDR` | 後台監聽位址，預設 `0.0.0.0:19090`。改成 `127.0.0.1:19090` 就只有本機連得到。 |

沒填 Postmark 的兩個值時，認證碼不會寄出，只會寫進 `.local/logs/admin.stdout.log`（找 `admin_login_code_not_mailed`），方便在本機先試用。

認證碼 6 位數，10 分鐘有效，輸錯 5 次作廢，同一個 email 每分鐘最多寄一次。登入後 7 天內不用再登入。其他管理員可以在後台的「管理員」頁新增。

## 從外網連線

遊戲服務本身仍然只綁 `127.0.0.1`，只有後台對外。要從外面連進來，需要讓 19090 埠到得了這台電腦，有兩種做法：

- **建議：** 用 Cloudflare Tunnel 之類的通道把一個 HTTPS 網址轉到 `http://127.0.0.1:19090`，並把 `MAPLEGO_ADMIN_ADDR` 改成 `127.0.0.1:19090`。這樣連線全程加密，也不用開路由器的埠。
- 直接開埠：在 Windows 防火牆與路由器放行 19090。這時請設定 `MAPLEGO_ADMIN_TLS_CERT` 與 `MAPLEGO_ADMIN_TLS_KEY`（憑證與私鑰的檔案路徑）讓後台自己走 HTTPS；沒有 HTTPS 時，登入狀態會以明文在網路上傳送。

## 設定

設定存在資料庫的 `ops_server_settings`。沒存過的項目沿用原本的環境變數，所以不開後台時行為與以前相同。存過之後以後台的值為準。

設定頁依類別分成七個分頁：倍率、遊戲功能、交易與商店、登入器介面、戰鬥與動作、突破上限、除錯。「儲存」一次存下所有分頁的修改，分頁標題旁的數字是該分頁還沒儲存的項目數。

| 設定 | 原本的環境變數 | 生效時機 |
|---|---|---|
| 經驗、楓幣、掉寶倍率 | `MAPLEGO_EXP_RATE`、`MAPLEGO_MESO_RATE`、`MAPLEGO_DROP_RATE` | 幾秒內 |
| Buff 疊加 | `MAPLEGO_STACK_BUFFS` | 幾秒內 |
| 重登保留 Buff | `MAPLEGO_RELOG_BUFFS` | 幾秒內 |
| 潛能功能 | `MAPLEGO_ENABLE_POTENTIAL` | 幾秒內 |
| 新版裝備說明、裝備能力比較 | `MAPLEGO_EQUIP_TOOLTIP`、`MAPLEGO_EQUIP_COMPARE` | 幾秒內，玩家下次換地圖或登入時套用 |
| 精靈商人手續費、交易手續費 | `MAPLEGO_MERCHANT_FEE_RATES`、`MAPLEGO_TRADE_FEE_RATES` | 幾秒內，玩家下次換地圖或登入時看到新數字 |
| 玩家交易可放現金道具 | `MAPLEGO_TRADE_CASH_ITEMS` | 幾秒內，玩家下次換地圖或登入時套用 |
| 宅配送達時間（分鐘，預設 60） | `MAPLEGO_PARCEL_DELAY_MINUTES` | 幾秒內，之後寄出的宅配照新時間；宅配視窗的說明在下次開視窗時跟著改 |
| 精靈商人可賣現金道具、商店價格顯示單位 | `MAPLEGO_MERCHANT_CASH_ITEMS`、`MAPLEGO_MERCHANT_PRICE_UNITS` | 幾秒內，玩家下次換地圖或登入時套用 |
| 每個世界的角色上限（1 到 60，預設 60） | `MAPLEGO_CHARACTER_SLOTS` | 幾秒內，玩家下次回到角色選擇畫面時套用；超過 15 需要用登入器。調低時已建立的角色照常顯示、登入和遊玩，只是不能再建立新角色 |
| 封包追蹤 | `MAPLEGO_TRACE_CHARACTERS`、`MAPLEGO_TRACE_FULL_PACKETS` | 幾秒內 |
| 等級突破與等級上限 | `MAPLEGO_INT_LEVEL`、`MAPLEGO_MAX_LEVEL` | 重啟服務器 |
| 能力值突破 | `MAPLEGO_LONG_STATS` | 重啟服務器 |
| HP/MP 突破 99,999 | `MAPLEGO_LONG_VITALS` | 重啟服務器 |
| 64 位元經驗值 | `MAPLEGO_LONG_EXPERIENCE` | 重啟服務器 |
| 楓幣與點數突破 21 億 | `MAPLEGO_LONG_MONEY` | 重啟服務器 |
| 傷害突破與上限 | `MAPLEGO_LONG_DAMAGE`、`MAPLEGO_LONG_DAMAGE_CAP` | 重啟服務器 |

需要重啟的項目會改變封包格式，不能在玩家連線中切換。儲存後在還沒重啟的服務旁會顯示「重啟後生效」。

手續費在「交易與商店」分頁一級一列地編輯：每一級是「成交金額達多少楓幣以上，收百分之幾」，金額可以寫 `1,000,000`、`100萬` 或 `1.5億`，最多 6 級，全部刪除就是不收。每列下方會顯示剛好那個金額要收多少，最下面可以輸入任意金額試算。金額沒有由小到大或百分比不在 0 到 100 時該列會標紅，改好才能儲存。環境變數仍用 `金額:百分比` 以逗號分隔的寫法，例如 `100000:0.4,1000000:0.9`。

倍率的作用範圍：經驗倍率乘在打怪經驗上（組隊與技能加成之前），楓幣倍率乘在怪物掉落的楓幣金額，掉寶倍率乘在怪物道具的掉落機率。任務獎勵不受影響。

## 登入器同步

登入服務在客戶端的版本握手之後、第一個原生封包之前，送出 `0x612`：

| 欄位 | 大小 | 內容 |
|---|---|---|
| version | 1 | 目前是 1 |
| features | 4 | bit0 等級突破、bit1 能力值突破、bit2 64 位元經驗、bit3 傷害突破、bit4 狙擊 Boss 公式 |
| max_level | 4 | 等級上限 |
| long_damage_cap | 8 | 單行傷害上限，關閉時為 0 |

登入器依這個封包安裝對應的修補，所以這些開關不再需要寫在 `open.ini`。

登入器的介面功能另外用 `0x615` 同步，內容是 4 位元組的位元遮罩：bit0 新版裝備說明、bit1 裝備能力比較。登入服務接在 `0x612` 之後送一次，世界服務在每次進地圖時再送一次，所以在後台切換後不用重啟，玩家換地圖就會套用。這兩項不改變封包格式；舊版登入器會忽略這個封包。

「戰鬥與動作」分頁的六個開關（預設都關）用同一個遮罩的 bit 5 到 bit 10：遠攻不揮空（`ranged_no_melee`）、全職業跳躍攻擊（`jump_attack_all_jobs`）、空中施放（`air_cast`）、法師空中瞬移（`air_teleport`）、全職業解除變身前置（`morph_skills`）、解除受擊無法操作（`no_hit_stun`）。它們解除的都是客戶端的限制，服務器的攻擊驗證只看位置與射程，不需要另外放行；修補點與實測紀錄在登入器的 docs/COMBAT_SWITCHES.md。

宅配送達時間用 `0x618` 同步（1 位元組版本 1、4 位元組分鐘數）。世界服務在每次進地圖與每次打開宅配視窗時送出，登入器把視窗上「宅配配送需要消耗12小時」那行改寫成實際時間；舊版登入器會忽略這個封包，畫面仍顯示 12 小時。

## 遊戲內的顯示設定

玩家在聊天輸入指令，服務器以 `0x613`（1 位元組項目、4 位元組數值）通知登入器；登入器套用並存在玩家自己的電腦上。這些指令不會顯示給其他玩家。

| 指令 | 作用 |
|---|---|
| `@設定` | 列出所有指令 |
| `@fps 60` | FPS 上限，0 為不限制，立即生效 |
| `@顯示 怪物 關` | 開關一個顯示圖層，立即生效 |
| `@解析度 1280x720` | 下次開啟遊戲生效 |
| `@視窗 開` / `@視窗 關` | 視窗或全螢幕，下次開啟遊戲生效 |
| `@背景輸入 開` | 下次開啟遊戲生效 |
| `@重設` | 全部還原成預設值 |

## GM 授權

後台的 GM 授權沿用既有的 QA GM 機制，授權時該帳號必須是離線狀態。

- **限時**：最長 24 小時，到期自動失效。
- **永久**：給常駐 GM 用，沒有到期時間，要在後台按「撤銷」才會取消。只有後台能給永久授權，世界服務的本機授權端點仍然只接受 24 小時內的授權。

有授權的角色在遊戲聊天輸入 `!help` 會看到 GM 指令的分類選單，`!help 1` 到 `!help 6` 列出各類指令。

兩種授權能用的指令不同：

- 限時和永久都能用：只影響自己的指令（補血、等級、職業、能力值、AP、SP、技能、道具、楓幣、測試地圖與測試怪物）以及查詢類（`!online`、`!rates`、`!whereami`）。
- 只有永久授權能用（說明裡標 ★）：`!map` 傳送到任何地圖、`!goto` 和 `!warphere` 在玩家之間傳送、`!dc` 讓玩家斷線、`!notice` 全伺服器公告、`!npc` 遠端開啟 NPC 對話、`!cash` 和 `!points` 取得 Gash 與楓葉點數。

每一道指令（包含被拒絕的）都會記錄在 `ops_qa_gm_commands`，公告內容和對象名稱在 `result` 欄的 `text`。

授權對象用搜尋選單挑：輸入角色或帳號名稱的一部分，從結果裡選角色。

「後台管理員」（誰可以登入後台）不在分頁列上，從右上角自己的 email 旁邊進入。

## 玩家的裝備與背包

在「玩家」分頁點角色名稱，會進入那個角色的頁面：左邊是照遊戲樣式畫的「裝備欄位」與「道具欄位」，滑鼠移到道具上會出現和遊戲一樣的說明（實際素質、可用卷軸次數、潛能）。

- **修改素質：** 點一件裝備，可以改 14 項素質、可用卷軸次數與已上卷次數，每項 0 到 32767。潛能與星力只顯示，不能在這裡改。
- **修改數量、刪除：** 點消耗、其他、裝飾、特殊欄的道具可以改數量（上限是該道具的堆疊上限）或刪除。
- **給予：** 右邊可以用名稱或編號搜尋道具後給予，也可以給楓幣、Gash、楓點；填負數是扣除。金額支援超過 21 億的大數字。
- **即時生效：** 玩家在線上時，修改經過他所在的世界服務執行，馬上出現在對方的遊戲畫面，不用重新登入。離線時直接寫入存檔。玩家正在換地圖、換頻道、交易或在商城裡時會請你稍後再試。Gash 與楓點存在帳號上，商城下次讀餘額時就是新的數字。
- **離線玩家：** 玩家列表預設顯示全部角色（線上排前面），右上可切到「只看線上」的即時狀態。離線角色一樣可以查看與修改。
- **不會蓋掉玩家剛做的事：** 送出修改時，後台會把你畫面上看到的那件道具（素質或數量）一起送出；服務器在鎖住角色後比對，只要玩家在這段時間用掉、強化或重新堆疊過，就整筆不套用，畫面重新載入後再改一次。按下儲存的當下才決定走線上還是離線，玩家剛好在登入或登出時會請你稍後再試，不會兩邊各寫一次。
- **記錄：** 每一次修改都寫進 `ops_admin_inventory_ops`（誰、什麼時候、改之前與改之後）。
- **目前不支援：** 寵物不能從這裡給予、修改或刪除。

道具圖示來自遊戲客戶端自己的 `.wz` 檔（服務器的 WZ 資料沒有圖）。用 `MAPLEGO_CLIENT_WZ_ROOT` 指到含有 `Item.wz` 與 `Character.wz` 的客戶端資料夾；沒設定時會找 `.local/client`，都沒有就改顯示道具名稱，其他功能不受影響。道具名稱與說明來自 `MAPLEGO_WZ_ROOT` 的 `String.wz`。

## 即時監控、公告與記錄

後台只會「去讀」世界服務，世界服務從不呼叫後台，也不會為了監控寫資料庫。後台停掉、當掉或資料庫變慢，遊戲都照常運作。

- **玩家（即時）**：每 3 秒向每個世界讀一次記憶體中的線上角色（等級、職業、頻道、地圖、HP/MP、經驗、楓幣）。有輸入搜尋文字時改查資料庫存檔。
- **公告**：可發給全服務器、指定世界、指定頻道或指定地圖。只有已經站在地圖裡的角色收得到，換頻道中或在商城的玩家收不到。每次發送都會留下記錄（誰、範圍、內容、收到人數）。
- **記錄**：一般、好友、隊伍、公會、聯盟聊天，組隊異動，完成的交易。保留 30 天。

世界服務把最近 4096 筆事件留在記憶體，後台每 2 秒取走並存進 `ops_admin_events`。後台停機期間若超過 4096 筆，較舊的會遺失；世界服務重啟時還沒被取走的也會遺失。

目前沒有記錄的：密語（服務器還沒有實作密語）、副本（服務器還沒有副本系統）。

世界服務的讀取端點只開在本機（`127.0.0.1:19081 + 世界編號 × 2`），需要 `MAPLEGO_RPC_TOKEN`：

| 端點 | 用途 |
| --- | --- |
| `GET /admin/monitor/players` | 線上角色的即時狀態 |
| `GET /admin/monitor/events?after=<seq>` | `seq` 之後的事件 |
| `POST /admin/monitor/notice` | 發公告，`{"channel":0,"map_id":0,"message":"..."}`，0 代表全部 |
