# 專業技術（生活技能）

專業技術村〈梅斯特鎮〉（地圖 910001000）的採集、製作、性向與疲勞度。資料來自 `MAPLEGO_WZ_ROOT` 的 WZ 匯出；沒有設定時這個功能不存在。

## 規則

| 項目 | 內容 |
|---|---|
| 採集類 | 藥草採集 92000000、採礦 92010000，只能學一種 |
| 製作類 | 鍊金術 92040000（需藥草採集）、裝備製作 92020000 與飾品製作 92030000（需採礦），只能學一種 |
| 等級 | 1 到 10；每級所需熟練度取自 `Skill.wz/920x.img` 的 `level/N/x`，滿了自動升級，多的熟練度帶到下一級 |
| 疲勞度 | 上限 200，每 180 秒恢復 1 點（離線也算） |
| 性向 | 六項各存累計經驗；採藥成功 感性 +5、採礦成功 洞察力 +5、製作成功 手藝 +40 |

放棄採集類之前要先放棄製作類；放棄製作類會一併忘記學過的配方。

## 採集

藥草堆與礦脈是地圖上的反應器（模板 1000xx、2000xx）。流程：

1. 客戶端送 `0x1A1`（反應器物件 ID）。服務器檢查後回 `0x178`：11 表示開始，其他代碼由客戶端顯示拒絕原因（沒有工具 1、等級不足 2、沒學 3/4、疲勞 5、太遠 6、有人在採 8）。
2. 客戶端每隔一段時間送一次 `0x17D`，服務器把反應器推進一個狀態（`0x1ED`）。
3. 第四下反應器消失（`0x1F1`），服務器結算並回 `0x115`，之後依地圖的 `reactorTime` 或模板的 `resetTime` 重生（`0x1EF`）。

成功率 90%，採集等級每高於／低於節點一級加減 10%。成功得到 1 個原料、20 熟練度（每差一級加減 2）；失敗得到藥草的根或母礦的碎塊，熟練度是十分之一。每次疲勞 +1（`notFatigue` 的節點不算）。

採到的東西直接進背包，不掉在地上；背包滿了就採集失敗。WZ 沒有節點的掉落表，所以產出取自該專業自己的精煉配方：第 n 號節點（0–9）給等級 n+1 精煉配方用的原料，練習用節點（10）同第 0 號，稀有節點（11）給全部。

## 製作

配方取自 `Skill.wz/Recipe_920x.img`。客戶端按「製作」後送 `0x100`（特效）、`0x101`（動作與時間，服務器廣播 `0x113`），進度條跑完再送 `0xFF`（配方 ID）。服務器在一次提交中扣材料、給成品、加熟練度／疲勞度／手藝，然後廣播 `0x114`。

- 藥草採集與採礦的精煉配方一定成功；製作類配方在等級不足時每差一級少 20%。失敗仍然消耗材料。
- 成品有多個時依 `probWeight` 抽一個。
- 需要配方道具的配方（`needOpenItem`）要先使用 251xxxx 道具學會（`0x83`）。
- 滑鼠停在配方上時客戶端用 `0xC7` 問成功率，服務器回 `0x8E`。

還不支援：分解（配方 ID 尾數 9000）與合成（9001）、有期限的成品（`period`）、秘密農場與礦山的 10 分鐘時限（`timeLimit`）、每日性向經驗上限。分解與合成會回「因未知理由而失敗」。

## 客戶端看到的資料

- 專業技術是技能紀錄：值為 `等級 << 24 | 熟練度`。學會的配方是配方 ID、等級 1 的技能紀錄，忘記時送等級 -1。兩者都隨進地圖的技能區段送出，變動時用 `0x31`。
- 疲勞度（遮罩 `0x80000`，1 位元組）與六項性向（`0x100000` 起，各 4 位元組，順序為領導力、洞察力、意志、手藝、感性、魅力）在角色能力區塊與 `0x2C`。
- 性向增加的聊天訊息是 `0x36` 類型 16。
