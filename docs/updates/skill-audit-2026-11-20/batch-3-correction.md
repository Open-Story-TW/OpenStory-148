# 第三批更正：50 項舊通過改為失敗（2026-11-20）

全清單更正為完成 **4,643／16,298 個檢查點（28.5%）**，全部檢查完成的技能 **291／1,502 項**。

依技能清單的驗收規則，同一檢查點以較新的有效實測為準。皇家騎士團、米哈逸、狂狼勇士、龍魔導士線與末日反抗軍線的新實測，使下列 50 項先前的通過改為失敗。其中多數是攻擊傷害：舊紀錄量自 11 月 18 日的舊測試版、使用剛建立的角色；新實測的角色帶著鬥氣球、連擊數與已學會的傷害被動，伺服器的傷害上限低於原版客戶端，因此判定失敗。末日反抗軍的 7 項是目前正式版服務器的數值錯誤，例如弩術精通的熟練度為 120，原版為 70。

修正已在整合測試版中，完成驗收後隨服務器新版發布並重測。
