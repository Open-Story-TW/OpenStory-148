# 整合測試進度與武陵道場原型（2026-11-20）

全清單目前完成 **5,049／16,235 個檢查點（31.1%）**，**296／1,502 項技能**的所有檢查都已完成。完整逐項清單已隨登入器 v0.1.13 收錄於登入器儲存庫 `docs/server/skill-audit/`。

## 整合測試版新進度（待完整實機驗收後併入正式版）

以下項目已完成單元測試並併入伺服器整合測試分支，實機驗收持續進行中：

- **武陵道場（開發中）**：完成一般模式 47 層樓、40 位頭目、各層分段計時（5～15 分鐘）、頭目出現位置、獨立房間與蕭公 NPC 流程；能量條滿 10,000 時可依原版提示以 `Ctrl+Alt+方向鍵` 施放竹竿千擊、金剛不壞與地火天擊，並確認無敵屏障期間阻擋受傷。完整道場技能驗收與排名系統尚在進行。
- **召喚獸跨圖與返場**：會跟隨移動的召喚獸（老鷹、鳳凰、火焰之魂、暗黑之眼、皇家騎士團精靈）於換地圖時隨主人移動，換頻道或從商城返回後可恢復。
- **技能與攻擊修正**：
  - 機甲戰神「開放之門」與「磁場」、區域槍手標記射擊。
  - 高爆擊率狀態後施放低爆擊率技能時，改以各段對應的爆擊率計算審核窗口，避免正常爆擊被誤判截斷。
  - 神射手等爆頭類技能對非首領目標的上限值視為秒殺。
  - 被動技能對特定攻擊的傷害加成（5110008、5220001、5311001、5810008、5920001）計入攻擊傷害上限，正常高傷害不再被截斷。
  - 能量獲得滿能量時套用原版攻擊、命中與迴避；毒炸彈解析爆炸座標；閃雷悍將 15101003 不再要求按住蓄力；龍魔導士「龍魂」套用 v148 WZ 防禦與速度。
