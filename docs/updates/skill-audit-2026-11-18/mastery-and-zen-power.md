# 武器熟練與蒼龍之力驗收（2026-11-18）

**267／1,502 項技能（17.8%）**完成驗收，**2,964／16,298 項檢查**通過，累計收錄 **5,299 張原版實機截圖**。

僧侶咒語精通（2300006）和俠盜精準之刀（4200000）各通過三項。原版客戶端分別以兩把合法武器比對，熟練加成在完整重啟客戶端後仍生效。
